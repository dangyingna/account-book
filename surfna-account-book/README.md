# 冲浪娜记账

一个简洁易用的本地记账应用，基于 Vue 3 + Vite 开发。无需后端或数据库，账单、预算和分类数据均保存在浏览器 localStorage 中，适合记录和分析个人日常收支。

## 功能清单

- **首页**：展示本月收入、支出、结余和账单明细，支持删除账单
- **记一笔**：记录收入或支出，支持一级/二级分类、金额、日期和备注
- **统计**：按月份查看收支汇总；通过 ECharts 饼图展示一级分类占比，点击可下钻查看二级分类；同步展示当月账单明细
- **预算**：为每个支出一级分类设置月度预算，实时展示已花费、剩余额度和使用进度，超支时醒目提示
- **分类管理**：自定义收入、支出的一级和二级分类，支持新增、修改和删除
- **数据管理**：导出 JSON 或 Excel 账单、导入本地 JSON 账单、二次确认后清空全部账单
- **页面导航**：基于 Vue Router 的五个页面路由，支持侧边栏切换、浏览器前进后退和直接访问
- **数据联动**：新增或删除账单、修改预算或分类后，首页、统计和预算数据自动更新

## 技术栈

- Vue 3
- Vite
- Vue Router
- Element Plus
- Pinia
- ECharts
- XLSX

## 本地启动

环境要求：已安装 Node.js 和 npm。

在仓库根目录执行：

```bash
cd surfna-account-book
npm install
npm run dev
```

启动后，打开终端显示的本地地址（默认为 `http://localhost:5173/`）即可使用。

## 构建与预览

```bash
npm run build
npm run preview
```

生产构建结果位于 `dist` 目录。

## 目录结构

```text
src/
  components/  公共组件（SideMenu 侧边栏）
  views/       首页、记一笔、统计、预算、设置页面
  stores/      Pinia 响应式状态与本地数据操作
  utils/       localStorage 工具函数
  router.js    页面路由配置
  App.vue      应用布局与路由出口
  main.js      应用入口
```

## 数据说明

数据只保存在当前浏览器和当前设备中，不会自动上传或同步。清除浏览器网站数据、换浏览器或在设置页清空账单后，数据可能无法恢复，建议定期在设置页导出 JSON 备份；Excel 文件适合查看和整理，不能用于导入。
